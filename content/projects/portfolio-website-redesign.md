A complete overhaul of the client's portfolio website with a modern, responsive design.

## Overview

The client needed a fresh online presence that better reflected their brand and
showcased their work. The previous site was slow, outdated, and difficult to
update.

## What was built

- **Next.js 16** with App Router and Server Components for maximum performance
- **Supabase** for authentication, database, and real-time subscriptions
- **Tailwind CSS** for a consistent, customizable design system
- **Admin dashboard** for managing clients, projects, and tasks
- **Public showcase** pages for sharing completed work

## Results

- Page load time reduced from 4.2s to 1.1s
- Mobile-first responsive design
- Admin can update portfolio content without touching code
- Client access restricted to their own data via Row-Level Security
